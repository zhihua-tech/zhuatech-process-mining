# 企业流程挖掘与优化平台企业能力

## 领域覆盖

- **数据源接入**：连接ERP、CRM、OA、ITSM和文件并登记抽取批次
- **事件日志**：标准化案例、活动、时间、执行人和业务属性
- **流程发现**：从事件序列生成实际流程模型和关键路径
- **流程变体**：识别主路径、长尾路径和异常高频变体
- **一致性检查**：将真实路径与标准流程对比并定位偏差
- **瓶颈分析**：分析等待、交接、拥塞和周期时间损失
- **返工分析**：识别重复活动、回退循环、重复审批和返工成本
- **时效与合规**：评估SLA、职责分离、跳步和控制点执行情况
- **改进闭环**：管理优化假设、责任人、收益、验证和持续监控

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对企业流程挖掘与优化平台关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `DATA_PLATFORM`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
